Step-by-Step macOS Setup Instructions

1
1-Click Auto Install
Mount the DMG & Double-Click "Install Focus"

Double-click Focus-1.0.0.dmg. In the opened DMG window, double-click Install Focus. If a previous version exists, it prompts to delete it and start a clean fresh install. It copies Focus to /Applications and automatically configures and starts the background service.

Alternative: You can also drag Focus.app into Applications — launching it will automatically self-register and start the background service without any terminal commands.

2
Auto Launch
Automatic Startup & Browser Dashboard

Focus boots its bundled PostgreSQL engine automatically (port 5433) and opens http://localhost:8484 in your default browser. Your personal dashboard is ready immediately.

3
Gatekeeper
Gatekeeper Verification ("Apple could not verify...")

If macOS blocks double-clicking with "Focus Not Opened — Apple could not verify Focus is free of malware", approve it in two quick clicks:

GUI method (No Terminal): Go to System Settings > Privacy & Security, scroll down to Security, and click Open Anyway next to Focus.

Or run this one-line command in Terminal to unblock permanently:

xattr -cr /Applications/Focus.app
4
Background Service
Automatic Background Service (Zero Commands Needed)

The background service (com.productivity.focus) runs silently in the background and auto-starts on login with zero terminal configuration. To inspect or manage via CLI (optional):

./bin/mac/focus status

To stop: ./bin/mac/focus stop | To start: ./bin/mac/focus start | To uninstall: ./bin/mac/uninstall-service.sh

Step-by-Step Linux Setup Instructions

1
Java
Verify or Install Java 17

Ensure Java 17 is available on your machine:

java -version

On Ubuntu/Debian: sudo apt install openjdk-17-jre

2
Launch
Launch Focus Standalone

Launch the executable Spring Boot fat JAR:

java -jar focus.jar

Or using CLI: chmod +x focus && ./focus start

3
Service
Optional: Install systemd Service

To run Focus automatically as a systemd user daemon:

./bin/linux/install-service.sh --user

Manage: systemctl --user status focus | systemctl --user stop focus

Why Focus?

Designed for professionals who value focus, high performance, and complete data privacy.

Zero Database Setup

PostgreSQL is compiled and bundled directly inside Focus. The application starts its own database on port 5433 and stops cleanly.

100% Private & Local

No cloud analytics, telemetry, or remote user tracking. Your tasks, attachments, and productivity statistics never leave your computer.

Clean Slate by Default

When you run Focus on a new machine, you get a clean workspace ready for your personal workflow. Starter records can be toggled in configuration.

Frequently Asked Questions

Common questions and troubleshooting.

Focus defaults to port 8484. If another process is using it, override via the SERVER_PORT environment variable:
SERVER_PORT=8090 java -jar focus.jar

Database records persist in postgres-data/ and uploaded file attachments in storage/ in the application directory. Download a complete backup ZIP or restore from Settings > Data management.

SPRING_PROFILES_ACTIVE=prod DB_URL=jdbc:postgresql://host:5432/db DB_USERNAME=user DB_PASSWORD=pass java -jar focus.jar
Focus bypasses its embedded database automatically when an external URL is configured.

In a terminal, press Ctrl + C for graceful shutdown. In daemon mode on macOS or Linux, run ./bin/mac/focus stop or ./bin/linux/focus stop. On Windows, run .\bin\win\focus.bat stop or close the console window. To completely uninstall on Windows, use Windows Settings > Apps or run .\bin\win\uninstall.bat.
